# SFU Anime Club - Ren
#### *Music, admin, trivia, fun commands and much more!*
[<img src="https://img.shields.io/badge/discord-py-blue.svg">](https://github.com/Rapptz/discord.py) [![Build Status](https://api.travis-ci.org/SFUAnime/Ren.svg?branch=prod)](https://travis-ci.org/SFUAnime/Ren) [![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg?style=flat-square)](http://makeapullrequest.com)

**Ren** is SFU Anime Club's main Discord bot, and is a forked version of [Red-DiscordBot by Twentysix and company](https://github.com/Cog-Creators/Red-DiscordBot/).  We have made changes to suit our uses.

# Contribute
We welcome changes that benefit the server as a whole!  Discuss in `#feedback` on the Discord server about your ideas.
